This repository is set up as a 0:/ drive for kOS, hence the lack of folders. Many early multi-stage probes upload and run scripts across different probes to save mass on the final probe. Many early files have deeply truncated or initialized names due to extremely limited disk space requiring minimizing the size of boot files by using shorter filenames. Generally speaking, the names use the following convention when shortened: [planetary body or unused if Earth]+[flier/orbiter/lander or general mission purpose]+[mk1/mk2/etc]+[blank if first stage/launcher, interstage, or final, or black if only one script is needed in totality]. 

p_dat and t_dat are text files exported from kOS from in-game sounding rockets for use in a launch trajectory optimization script I'm trying to slowly write in python. Format is {pressure/temperature,altitude] in .csv format. Data was taken every 0.01 seconds and continues until altitude begins to decrease. The underlying script that produced this data is tinybee.ks
